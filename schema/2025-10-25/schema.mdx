## Top-Level Structure & Umbrella Dimensions

`FayManifest` serves as the declarative `package.json` of an `iFay` instance (`additionalProperties: false`):

| Umbrella Dimension | JSON Schema Field(s) | Requirement & Semantics |
| --- | --- | --- |
| `schemaVersion` / Edition | `version` (`semver`) & `$schema` | SemVer 2.0.0 manifest release version validated against Draft 2020-12 (`urn:ifay:schema:faymanifest:v1.0.0`). |
| `fayId` | `fayId` (optional `string`) | Canonical accountability identifier (`ifay_<base32>` or `cofay_<base32>`) governed by the `FayID` specification; auto-provisioned during `FayGer` assembly when omitted. |
| `phase` & Control Mode | `controlMode` (`"command" \| "ego" \| "autonomous"`) | Execution autonomy boundary; progressive conformance `phase` (`Phase 1`–`Phase 5`) is deterministically resolved from declared components by `@ifay/sdk` and `@ifay/ifacts`. |
| `components` | `modules`, `protocols`, `drivers`, `ego`, `permissions` | Required `modules[]` and `protocols[]` (`snake_case` `componentId` + SemVer range), plus optional hardware/service `drivers[]` (`@scope/name`), `ego` alignment boundaries, and scoped `permissions`. |
| Package Metadata | `name`, `description`, `vendor` | Required non-empty human-readable identity and publisher metadata for the assembled `Fay` package. |

## Top-Level Manifest Model

All `FayManifest` declarations conform to [`../faymanifest/faymanifest.schema.json`](../faymanifest/faymanifest.schema.json):

- **Schema & Package Version (`schemaVersion` / `version`)**: Strict SemVer 2.0.0 `version` paired with JSON Schema Draft 2020-12 (`urn:ifay:schema:faymanifest:v1.0.0`), plus required `name`, `description`, and `vendor`.
- **Accountability Identity (`fayId`)**: Optional non-empty string delegated to `FayID` (`ifay_` / `cofay_`), bound to an accountable `Human Prime` or organization at assembly time.
- **Autonomy & Stage (`controlMode` / resolved `phase`)**: Required `controlMode` (`"command"`, `"ego"`, or `"autonomous"`), with cumulative `Phase 1`–`Phase 5` stage requirements enforced by `@ifay/ifacts`.
- **Declarative Components (`components`)**: Required `modules[]` and `protocols[]` arrays (`^[a-z][a-z0-9_]*$`), plus optional `drivers[]` (`@scope/name`), `ego` model constraints, and `permissions` scopes.
